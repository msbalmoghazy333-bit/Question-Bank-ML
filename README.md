# AI216 — Machine Learning Question Bank (Chapters 1-7)

Interactive question bank for **AI216: Machine Learning and Pattern Recognition**.

Unified single-file quiz (`index.html`, originally `Q bank All Chapters 1-7.html`) with **378 questions**:

- Chapter 1: The Machine Learning Landscape (52)
- Chapter 2: End-to-End Machine Learning Project (59)
- Chapter 3: Classification (64)
- Chapter 4: Training Models Part I (50)
- Chapter 5: Training Models Part II (51)
- Chapter 6: Support Vector Machines SVM (61)
- Chapter 7: Decision Trees DTs (41)

## Features
- Free navigation between chapters via tabs (All / Ch1–Ch7), with chapter dividers in All view
- Official answer key synced from the highlighted PDF (`AI216_Machine_learning_and_Pattern_Recognition_QB_Q_&_A_2025_docx.pdf`)
- Arabic explanations (ML terms in English)
- Answered-Only Evaluation: unanswered questions are skipped (no coloring, no explanation)
- Progress counter: `Answered: X / Total (Y Left) | Score: Correct / Answered`
- Reset Quiz clears radios, colors, explanations, and the score display

## Usage
Open `index.html` in any browser, pick a chapter tab, answer, then **Submit Answers**.
To reset the current view, use **Reset Quiz**.

Note: switching chapter tabs re-renders that chapter (same behavior as the original 2-chapter files), so submit a chapter before moving on.
